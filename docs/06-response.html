Question. Does cell-type composition differ between responders and non-responders, and is the answer inside MMR-deficient tumours the same as across the whole cohort? Cohort. Two, drawn side by side in every figure: all classifiable patients (n = 225) and the MMR-deficient subset of them (n = 107). Reads. The master (built on demand by get_master()), the FlowPath annotation tree, and the survival endpoint the master carries. Out of scope. Survival modelling itself -> 04-survival. The same composition panels keyed on aneuploidy -> 05-aneuploidy-mmrd.

This report is the response-keyed counterpart of Part 2 of 05-aneuploidy-mmrd. Every panel, normalization and test is the one used there; the only thing that changes is the grouping variable on the x-axis, which is treatment response rather than aneuploidy class. Keeping the two reports structurally identical is deliberate — it is what makes the two groupings comparable rather than two separate analyses that happen to use the same cells.

Both cohorts are drawn for every figure, always in the same order (all patients first, MMR-deficient second). Report 05 restricts to MMRd because MMR deficiency is itself a route to genomic instability and would otherwise confound an aneuploidy contrast. Response has no such built-in confound with MMR status, so the whole cohort is the primary cohort here and the MMRd panel is the stratified check.

Defining response

Response is a landmark on the survival endpoint the pipeline is already configured with: attend_cols$surv_time / attend_cols$surv_event, which currently point at progression-free survival in months. A patient still progression-free past 6 months is a responder; one who progressed or died at or before 6 months is a non-responder. The cut lives in attend_thresholds$response_months, so changing it changes every figure below and nothing else, and repointing attend_cols$surv_time at overall survival changes what “response” means here without touching this report.

The third group is the one that decides whether the definition is honest. A patient whose follow-up simply stopped before the landmark — censored, no event recorded — has no observable response status at all. Counting them as non-responders would score lost follow-up as treatment failure and inflate the responder arm by comparison. add_response_class() returns them as NA instead, and the table below is where they are reported rather than quietly dropped: 20 of 245 patients cannot be classified.

An event after the landmark does not demote a responder. The question is what had happened by month 6, not eventual outcome, so this is a binary contrast and not a survival model — the survival models themselves are all in 04-survival.

Cell-type composition by response

“Cell type” is phenotype_clean, the parenthetical phenotype label in the FlowPath export (changeable in code/load_phenotypes.R). Every count is taken inside the annotated region and expressed as a fraction, but the denominator changes the question, so all three are shown — this is the same three-way normalization report 05 uses:

Normalization Denominator The question it answers
all cells inside every cell in the annotation what fraction of the tissue is this cell type?
tumour cells inside tumour cells only how much of this cell type per unit of tumour?
CD45+ cells inside leukocytes only what is the composition of the immune compartment?

Each is drawn twice per cohort: the raw fraction with a Wilcoxon rank-sum test, and the arcsine-square-root-transformed fraction with a two-sample t-test. Agreement between the two is reassurance; disagreement means the result depends on the test rather than on the data. No multiple-testing correction is applied anywhere in this report, and with one test per cell type per normalization per cohort that is many comparisons, so every p-value here is descriptive.

Every cell type is drawn in one figure per normalization and cohort, on a single shared y axis, exactly as in report 05: a panel’s height reads as that cell type’s abundance relative to every other one, rather than against a rescaled axis of its own. Each cohort’s axis is computed from its own patients, so read the adjacent pair on which cell types moved, not on absolute box heights.

The axis stops at the largest upper whisker in the figure (Q3 + 1.5 IQR over every class x cell-type cell), not at the largest value, and the p-value label is placed inside that range by the same call. Both follow from one measurement: ggpubr derives its default label height from the plot-wide maximum, so a single extreme patient simultaneously flattened every box and parked every p-value at the ceiling, where it read as no p-value at all. The range is a zoom (coord_cartesian()), so every patient is still in the box statistics and in the test — nothing is dropped, and a point above the axis is counted in the subtitle. Groups smaller than attend_min_box_n still show a median crossbar instead of a box.

The pre-specified primary contrast

Of everything above, one comparison is designated primary: CD45+ / all cells inside, tested with the arcsine-square-root transform and a two-sample t-test, on the whole cohort. The Wilcoxon on the raw fraction is reported next to it as a companion, not a substitute, and the MMR-deficient version of the same contrast is secondary — it is the stratified check, and it can and does degrade to a skip when counts are missing.

Naming one primary endpoint in advance is what keeps this from being a search across twelve panels for the smallest p-value. It mirrors the primary contrast in 05-aneuploidy-mmrd, which is the same metric under the same test against the other grouping.

resp_arcsin_t_wilcox <- function(df, cohort_label, metric_, denom_) {
  d <- df |> dplyr::filter(metric == metric_, denom_label == denom_, is.finite(frac),
                           !is.na(response_class)) |>
    droplevels()
  tab <- table(d$response_class)
  if (length(tab) < 2 || any(tab < 2)) {
    message(cohort_label, " ", metric_, " / ", denom_,
            ": insufficient n per response arm — skipping.")
    return(invisible(NULL))
  }
  t_res <- t.test(arcsin_sqrt(frac) ~ response_class, data = d)     # primary
  w_res <- wilcox.test(frac ~ response_class, data = d)             # companion
  cat(sprintf("%-14s %-10s / %-20s  n=%d (resp=%d, non=%d)  arcsin-t p=%.3g  Wilcoxon p=%.3g\n",
      cohort_label, metric_, denom_, nrow(d), tab[["responder"]], tab[["non-responder"]],
      t_res$p.value, w_res$p.value))
  list(d = d, t = t_res, w = w_res)
}

Does the response effect differ between MMR strata

The two cohorts above are drawn side by side but never compared to each other, and looking at two p-values is not a test of whether they differ. This model is: arcsin(sqrt(CD45+/all cells inside)) ~ response_class * mmr_group, fitted on both MMR groups at once from imm_all. The interaction row is the one of interest — a large coefficient there means the response effect is not the same in MMRd and MMRp, which is what would justify reading the stratified panels separately rather than as one result. No correction is applied, and at this cohort size the interaction is expected to be underpowered.

imm_int <- imm_all |>
  dplyr::filter(metric == "CD45+", denom_label == "all cells inside", is.finite(frac)) |>
  dplyr::left_join(master_grp |> dplyr::select(pid, mmr_group), by = "pid") |>
  dplyr::filter(!is.na(mmr_group), !is.na(response_class)) |>
  dplyr::mutate(y = arcsin_sqrt(frac)) |>

if (nrow(imm_int) > 4 && dplyr::n_distinct(imm_int$response_class) == 2 &&
    dplyr::n_distinct(imm_int$mmr_group) == 2) {

Response against aneuploidy class

The direct cross-tabulation of the two groupings — the one in 05-aneuploidy-mmrd against the one used here — with a Fisher exact test on the 2×2. Everything in this report is drawn on the same cells report 05 draws, so if these two splits largely coincide then the two reports are describing one contrast under two names rather than two independent ones. The test is on patients, not images.
